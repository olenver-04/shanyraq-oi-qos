# 🏡 Шаңыраққа ой қос!

Интерактивті веб-сайт для урока казахского языка и литературы. Темы: «Киіз үй – ғажап сәулет туындысы», «Тырнақша», «Дизайн өнерінің даму тарихы», «Жақша», «Нүктелі үтір».

Сайт позволяет ученикам оставлять ответы с телефона, а преподавателю выводить живую стену на проектор и управлять сообщениями.

## ✨ Возможности

- **✍️ Сөйлем құрастыр:** предложение с «кавычками», (скобками) или точкой с запятой (;).
- **🎨 Мен дизайнер болсам...:** идея дизайна современной юрты.
- **💭 Бүгін мен білдім...:** короткая рефлексия по уроку.
- Ввод имени ученика.
- Большой QR-код, который ведёт на форму ответов.
- Живая стена, автоматически обновляющаяся каждые 2 секунды.
- Панель преподавателя с паролем: удалить отдельный ответ, очистить выбранную категорию или всё целиком, выбрать текущую активность, экспортировать CSV.
- Текстовые ответы безопасно экранируются при отображении.

## 🔗 Адреса

| Кому | Ссылка |
|---|---|
| Проектор: стена ответов | `https://ВАШ-САЙТ.streamlit.app/` |

QR-код генерируется автоматически из текущего адреса приложения.

## ☁️ Как опубликовать на GitHub + Streamlit Community Cloud

1. Откройте https://github.com/new и создайте **отдельный публичный репозиторий**, например `shanyraq-oi-qos`. Ваш NanoWall при этом не изменяется.
2. Распакуйте ZIP. Загрузите **содержимое папки**, а не сам ZIP. В корне репозитория должны находиться `app.py` и `requirements.txt`. Папка `.streamlit` необязательна для запуска, но содержит цветовую тему.
3. Нажмите **Commit changes**.
4. Откройте https://share.streamlit.io/, войдите через GitHub, нажмите **Create app → Yup, I have an app**.
5. Выберите свой репозиторий, ветку `main` и **Main file path: `app.py`**. Введите желаемый App URL, нажмите **Deploy**.
6. После публикации откройте **App settings → Secrets** и добавьте пароль преподавателя (ниже). Сохраните.
7. Откройте страницу на проекторе и попросите студентов сканировать QR-код.

### 🔐 Настройка панели преподавателя

Ни в коем случае не публикуйте пароль в GitHub или в файле `app.py`.

В Streamlit Cloud → приложение → **App settings → Secrets** добавьте:

```toml
ADMIN_PASSWORD = "придумайте-длинный-личный-пароль"
```

Для работы локально можно задать переменную окружения `ADMIN_PASSWORD` или создать локальный (игнорируемый Git) файл `.streamlit/secrets.toml` с этой строкой.

## 💻 Локальный запуск (не обязателен для учеников)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ⚠️ Важные ограничения

1. Ответы хранятся в **локальной базе SQLite внутри облачного контейнера**. Она общая для всех пользователей одного работающего экземпляра приложения, но **может исчезнуть после перезапуска или сна приложения**. Чтобы сохранить итоги занятия, скачайте CSV **до** окончания занятия и перезапуска приложения. Для долговременного хранения потребуется внешняя БД.
2. Это открытая форма по ссылке: ученики вводят имя самостоятельно. Сайт не подтверждает личность ученика.
3. Ответы сразу видны на проекторе. Перед демонстрацией полезно предупредить студентов, что имя и текст будут публичны для класса.
4. На бесплатном хостинге после паузы первая загрузка может занимать некоторое время. Откройте сайт за 5–10 минут до урока и проверьте с телефона.
